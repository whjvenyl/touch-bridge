# Building from Source

TouchBridge has multiple components with different build systems. This guide covers each one.

## Prerequisites

<CodeGroup>

```bash title="Xcode Command Line Tools"
xcode-select --install
```

```bash title="Build dependencies"
brew install protobuf swift-protobuf xcodegen
```

</CodeGroup>

## First-time setup

Generate the protobuf Swift code (gitignored, required before any build):

```bash
bash protocol/generate.sh
```

## All-in-one build

```bash
bash scripts/build-all.sh           # debug build
bash scripts/build-all.sh release   # release build
bash scripts/build-all.sh test      # build + run tests
```

This builds protocol, daemon, PAM, and menubar app. It does not build companion apps.

## Individual components

<Tabs>
  <Tab title="Protocol">

  ```bash
  cd protocol/swift
  swift build
  swift test
  ```

  </Tab>
  <Tab title="Daemon">

  ```bash
  cd mac
  xcodegen generate
  xcodebuild -project TouchBridge.xcodeproj -scheme touchbridge build
  xcodebuild -project TouchBridge.xcodeproj -scheme touchbridge test
  ```

  ### Run tests by suite

  ```bash
  xcodebuild -project TouchBridge.xcodeproj -scheme touchbridge test \
    -only-testing:TouchBridgeCoreTests/ChallengeManagerTests
  xcodebuild -project TouchBridge.xcodeproj -scheme touchbridge test \
    -only-testing:TouchBridgeCoreTests/KeychainStoreTests
  ```

  </Tab>
  <Tab title="PAM module">

  ```bash
  make -C mac/pam
  ```

  Produces `mac/pam/pam_touchbridge.so` (arm64 + x86_64).

  </Tab>
  <Tab title="Menubar app">

  ```bash
  cd mac
  xcodegen generate
  xcodebuild -project TouchBridge.xcodeproj -scheme TouchBridgeMenu build
  ```

  The menubar app auto-bundles the daemon binary and PAM module into its Resources.

  </Tab>
  <Tab title="iOS companion">

  ```bash
  cd companion/ios
  xcodegen generate
  open TouchBridge.xcodeproj
  ```

  Or build from the command line:

  ```bash
  xcodebuild -project TouchBridge.xcodeproj -scheme TouchBridge \
    -sdk iphonesimulator -destination 'generic/platform=iOS Simulator' build
  ```

  </Tab>
  <Tab title="Android companion">

  ```bash
  cd companion/android
  ./gradlew :app:assembleDebug
  ./gradlew :wear:assembleDebug
  ```

  Requires Android Studio or Android SDK with build tools.

  </Tab>
</Tabs>
