# Installation

## Requirements

| Component | Requirement |
|-----------|-----------|
| macOS | 13.0 (Ventura) or newer |
| Xcode | 15.0 or newer |
| Swift | 5.9 or newer |
| Bluetooth | BLE support (all modern Macs) |
| Companion | iOS 16+, Android 8+ |

## Build from source

<Steps>
  <Step title="Clone the repository">

  ```bash
  git clone https://github.com/HMAKT99/UnTouchID.git
  cd UnTouchID
  ```

  </Step>
  <Step title="Build and install">

  ```bash
  sudo bash scripts/install.sh
  ```

  The install script:
  - Generates protobuf code and builds the daemon via Xcode
  - Builds the PAM module as a universal binary
  - Ad-hoc signs the PAM module
  - Installs to `/usr/local/bin/` and `/usr/local/lib/pam/`
  - Creates the LaunchAgent for auto-start
  - Patches `/etc/pam.d/sudo` (with backup and confirmation)

  </Step>
  <Step title="Pair your device">

  Open the **TouchBridge** menu bar app, click **Pair New Device**, and scan the QR code with the TouchBridge app on your phone.

  Or use the CLI:

  ```bash
  touchbridge pair
  ```

  </Step>
  <Step title="Test it">

  ```bash
  sudo ls
  ```

  A biometric prompt appears on your phone. Approve it and `sudo` succeeds. Deny or timeout and it falls through to password.

  </Step>
</Steps>

## Uninstall

```bash
sudo bash scripts/uninstall.sh
```

This restores your original PAM configuration and removes all TouchBridge files.
