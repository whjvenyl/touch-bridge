# TouchBridge

Use your phone's fingerprint or Face ID to authenticate `sudo`, screensaver unlock, and other macOS auth prompts — instead of typing your password.

Free, open source alternative to Apple's $199 Touch ID keyboard. Works with iPhone, Android, Apple Watch, or Wear OS.

## How it works

<Steps>
  <Step title="Install">Install the daemon and PAM module on your Mac.</Step>
  <Step title="Pair">Pair your phone or watch via QR code.</Step>
  <Step title="Authenticate">When you run `sudo`, a biometric prompt appears on your phone. Approve it and sudo succeeds.</Step>
</Steps>

The approval happens over Bluetooth Low Energy (BLE) with end-to-end encryption. Your private key never leaves the Secure Enclave (iOS) or Android Keystore.

## Quick start

```bash
git clone https://github.com/HMAKT99/UnTouchID.git
cd UnTouchID
sudo bash scripts/install.sh
```

Then open the TouchBridge menu bar app and pair your device.
